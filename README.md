# Room reservation project

### This project is for the whole first semester.

## Lists of what things is going to be in this project:

1. A login to room reservation website page

	- A user login

	- A administrator login

2. Room reservations list page

	- Edit/Remove reservations

3. Calendar page

	- Reservation plans

	- reservation dates

4. Admin panel page

	- Create, Read, Update, Delete rooms

	- Adding new room

	- Reservation history

# How to test out the project for Website tester
